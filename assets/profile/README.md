# Profile assets

All six profile modules are native SVG with vector text, geometry and icons. Light/dark themes and desktop/mobile variants are included.

All interface text, labels, headings, body copy, display numerals and ASCII use one monospace font stack: Menlo, Consolas, monospace. Embedded source screenshots retain the original product typography. Native README links and text details use semantic samp elements for monospace rendering.

The process panel uses symbolic 0-to-1 and 01 Explore / 02 Design / 03 Build / 04 Refine, not audience or performance statistics.

The After Hours cover is based on Eagle item MWM9UAGWHTOSA. The atmosphere photo is Eagle item MWM9UMB2T32RW. Both were collected from the Flova Skill page and are decorative references, not original project credits.

Project imagery comes from the public innate-studio, quote0-agent-board, Pinny and SoundPin repositories. The avatar is the public realruian GitHub avatar.
